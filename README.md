# 文チェック — 送信前確認ツール（PWA版）

配信のコメント欄やDMなど、オンラインでの日本語のやり取りに慣れていない人向けの「送信前チェック」ツールです。
文章を貼り付けると、

- **整えた文**：主語・述語を補って自然な日本語に直したバージョン
- **送る前の確認**：情報が足りない点・意図が伝わりにくい点を指摘し、埋めるべき質問を提示

の2つを表示します。PWA（Progressive Web App）として作られているので、ブラウザから「アプリとしてインストール」して、独立したウィンドウで使えます。

## ファイル構成

| ファイル | 役割 |
|---|---|
| `index.html` | 本体（画面・ロジック） |
| `manifest.json` | PWAの設定（アプリ名・アイコン・表示モード） |
| `service-worker.js` | オフラインでも画面を開けるようにするキャッシュ処理（AnthropicへのAPI通信はキャッシュしません） |
| `icon-192.png` / `icon-512.png` | アプリアイコン |

## 使い方（利用者向け）

1. 公開したURL（例：`https://ユーザー名.github.io/リポジトリ名/`）をブラウザで開く
2. 右上の「APIキーを設定」から自分のAnthropic APIキーを入力して保存
   - キーは [console.anthropic.com](https://console.anthropic.com/settings/keys) から発行できます
   - キーはこの端末のブラウザ（localStorage）にのみ保存され、Anthropicへの通信以外には送信されません
3. アドレスバー右側の「インストール」アイコン（Chrome/Edge）、またはメニューの「アプリをインストール」からインストール
   - スマホの場合はブラウザメニューの「ホーム画面に追加」
4. インストール後はデスクトップやタスクバー、Dockのアイコンから開けます
5. テキストエリアに送りたい文章を貼り付けて「チェックする」を押す

> 画面の表示はオフラインでも開けますが、AI判定にはインターネット接続が必要です（Anthropicへの通信のため）。

## なぜ各自でAPIキーが必要なのか

このツールはAnthropicのClaude APIを直接ブラウザから呼び出す方式（bring your own key）で作られています。
共有のAPIキーを埋め込むと誰でもキーを盗み見て使えてしまい、悪用や高額請求のリスクがあるため、利用者ごとに自分のキーを使う設計にしています。この方式なら、API利用料は使う人自身の負担になり、あなた（配布者）に費用は発生しません。

チームやコミュニティ内など、信頼できる相手限定で「共有のキーで使いたい」場合は、サーバー（Cloudflare Workersなど）でキーを隠すプロキシ方式に変更する必要があります。

## 公開方法（GitHub Pages）

1. このリポジトリをGitHubに作成し、`index.html` / `manifest.json` / `service-worker.js` / `icon-192.png` / `icon-512.png` / `README.md` をコミット
2. リポジトリの **Settings → Pages** を開く
3. **Branch** を `main`（または公開したいブランチ）、フォルダを `/ (root)` に設定して保存
4. しばらくすると `https://ユーザー名.github.io/リポジトリ名/` でアクセス可能になります
5. HTTPS配信であればPWAのインストール条件は満たされます（GitHub Pagesは自動でHTTPS）

## 注意事項

- API利用には料金がかかります（利用者本人のAnthropicアカウントに課金されます）
- ブラウザの開発者ツールを開けばAPIキーが見える状態になるため、自分専用・信頼できる範囲での利用を前提にしています
- 生成される内容はAIによる提案です。最終的な文章は自分で確認してから送ってください
- アプリの中身（見た目・ロジック）を更新した場合、利用者側は再度ページを開くとService Workerが新しいバージョンを取得します（`service-worker.js` 内の `CACHE_NAME` の値を変えると確実に更新されます）
